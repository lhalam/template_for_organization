# Python Project Template

This is a template for Python projects with best practices.

## Project Structure

```
project/
├── src/
│   └── main.py
├── tests/
│   └── test_main.py
├── .gitignore
├── requirements.txt
├── README.md
└── LICENSE
```

## Getting Started

### Prerequisites

- Python 3.8 or higher
- pip

### Installation

```bash
pip install -r requirements.txt
```

### Running

```bash
python src/main.py
```

### Testing

```bash
pytest
```

## Development

This project follows Python best practices:
- PEP 8 style guide
- Type hints
- Unit tests
- Documentation
